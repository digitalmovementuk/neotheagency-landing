# Copy Blocks — Universal 7-Block Structure (DE/EN)

Use for populated artifacts (B and D).

1) H1 — exact-match target keyword.
2) H2 tagline — outcome-focused statement.
3) Opening (2 sentences) — keyword in first 15 words; brand in sentence 2.
4) "Was ist / What is {keyword}?" — definition + 4 business-effect bullets.
5) "Warum / Why professional {keyword}" — 4 value blocks with bold leads.
6) "{Brand}: Wie wir / How we do {keyword}" — authority block, 3 subsections, founder credibility.
7) CTA close — outcome question + contact action referencing hero form.

Length targets:
- Master pages: 900-1100 words.
- Geo pages: ~800 words.
- Geo token discipline: location mention 2-3 times max on Tier 2/3 pages.
